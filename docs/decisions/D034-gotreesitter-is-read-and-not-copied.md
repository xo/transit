# D34. gotreesitter can be read, and no code is copied from it

Status: Decided.

Ken decided on 2026-09-29, answering question 11, that transit ports every
file from upstream and copies no code from
[gotreesitter](https://github.com/odvcencio/gotreesitter). A person can read
a scanner of gotreesitter to find a fault in a port of the same scanner.
